# prestashopheaven/build-rules-code

Module-Factory rules for module code: structure, main class, install, database, PHP, docblocks, hooks, security, PrestaShop 8/9 compatibility, dependencies, packages and the DDD + CQRS architecture.

## Use when

When code of a module is designed or written: the rules of STR, MOD, INS, DB, PHP, DOC, HK, SEC, CMP, DEP, PKG and ARCH.

## Install

```
composer require prestashopheaven/build-rules-code
```
