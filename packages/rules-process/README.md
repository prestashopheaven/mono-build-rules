# prestashopheaven/build-rules-process

Module-Factory rules for the process: versions and releases, context for Claude, the git workflow, the demo shop, parallel sessions and the update system.

## Use when

When a module is released, published, committed or worked on next to other sessions: the rules of REL, CTX, GIT, DEMO, PAR and UPD.

## Install

```
composer require prestashopheaven/build-rules-process
```
