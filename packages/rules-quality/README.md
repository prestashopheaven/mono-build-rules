# prestashopheaven/build-rules-quality

Module-Factory rules for quality: tests, tooling, tests on real PrestaShop shops and the internal test shop.

## Use when

When tests are written or the definition of done runs: the rules of TST, TOOL, TEST and TS.

## Install

```
composer require prestashopheaven/build-rules-quality
```
