# prestashopheaven/build-rules-frontend

Module-Factory rules for what merchants and customers see: templates and assets, back office and Symfony, front controllers and multistore.

## Use when

When templates, JavaScript, back-office pages, front controllers or multistore behaviour of a module are built: the rules of TPL, BO, FC and MS.

## Install

```
composer require prestashopheaven/build-rules-frontend
```
