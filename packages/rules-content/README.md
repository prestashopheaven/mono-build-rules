# prestashopheaven/build-rules-content

Module-Factory rules for content: translations, manuals, marketing texts, screenshots and logos.

## Use when

When texts, translations, documentation or marketing of a module are written: the rules of TR, DOCS and MKT.

## Install

```
composer require prestashopheaven/build-rules-content
```
